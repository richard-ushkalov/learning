static    →  в потоке.   Место занимает. Сдвинуть нельзя.
relative  →  в потоке.   Место занимает — но рисуется со смещением.
absolute  →  ВЫПАЛ.      Места не занимает. Соседи о нём не знают.
fixed     →  ВЫПАЛ.      Места не занимает. Привязан к окну.
sticky    →  в потоке.   Место занимает. При прокрутке прилипает.

position: relative без смещений — не бессмыслица, а намеренный приём.

4.5 Что создаёт контекст наложения

Список знать полезно — половина «необъяснимых» багов отсюда:

корневой элемент <html>
position: relative / absolute  + z-index ≠ auto
position: fixed / sticky        — ВСЕГДА, даже без z-index
opacity меньше 1
transform, filter, backdrop-filter, perspective, clip-path, mask
will-change с любым из перечисленного
flex/grid-элемент с z-index ≠ auto
isolation: isolate

Обрати внимание на две строки.

position: fixed и sticky создают контекст всегда. Даже без z-index. Поэтому потомок фиксированной шапки никогда не всплывёт выше самой шапки.

opacity: 0.99 создаёт контекст. Визуально неотличимо от единицы — а порядок наложения перестроился. Это тот самый баг, который ищут часами: «я всего лишь чуть притушил блок». То же с transform — добавил анимацию, сломал z-index в другом месте.

4.6 isolation: isolate
css
.widget { isolation: isolate; }

Создаёт контекст намеренно, ничего не меняя визуально и не требуя position. Смысл: запереть z-index компонента внутри него, чтобы его внутренние слои не воевали с остальной страницей. Полезная штука, когда пишешь переиспользуемые блоки.
