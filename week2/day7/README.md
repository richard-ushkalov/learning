## Задача

1. Показать список игроков. У каждого — имя, число забитых шаров, число фолов и статус
2. Статус считается так: 4 фола и больше — «дисквалификация», 8 забитых — «победа», иначе — «в игре»
3. Показать имя победителя отдельной строкой. Победитель — тот, у кого 8 забитых и меньше 4 фолов. Если такого нет — «Победитель не определён»
4. Показать средний процент забитых по всем неди­сквалифицированным игрокам, округлённый до целого. За 100% берётся 8 шаров
