День 2 — Flexbox: раскладка ВНУТРИ потока

display: flex на КОНТЕЙНЕРЕ → прямые дети становятся items
две оси: главная (задаёт flex-direction) + поперечная
justify-content → главная | align-items → поперечная
   при column они меняются местами — вертикаль/горизонталь
gap резервируется ДО того, как justify-content делит остаток
flex-grow делит только СВОБОДНОЕ место
   flex: 1 = 1 1 0 → basis обнулён → честные пропорции
flex-shrink взвешен по basis: крупные отдают больше
min-width: auto — пол, из-за которого shrink не срабатывает
wrap → строки НЕЗАВИСИМЫ
   align-items = дети в строке | align-content = строки в контейнере

День 3 — position: выход ИЗ потока

главный вопрос: занимает ли элемент место в потоке?
   static ✓  relative ✓  absolute ✗  fixed ✗  sticky ✓

relative  → смещение от своего места, место остаётся (призрак)
absolute  → координаты от padding-box ближайшего позиционированного предка
fixed     → якорь всегда окно; ломается предком с transform
sticky    → relative до порога, дальше fixed; умирает от overflow у предка

z-index только на позиционированных (+ flex/grid items — исключение)
контекст наложения запечатывает слои внутри себя
   создают: fixed, sticky, opacity<1, transform, z-index≠auto, isolation

2.7 Инструмент нулевой специфичности
css
:where(.card, .panel) p { color: gray; }

:where() — псевдокласс, который не добавляет специфичности вообще, всё внутри него считается нулём. Здесь суммарно 0,0,1, как у голого p. Нужно, когда пишешь базовые стили, которые должны легко переопределяться. Пригодится в компонентных библиотеках; пока просто знай, что такой инструмент есть.
