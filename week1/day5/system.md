Строим руками

Берём базу — размер основного текста, 16px = 1rem. И коэффициент, на который умножаем при переходе на ступень вверх. Возьмём 1.25 — это «плюс четверть».

Вверх:

база          16
+ четверть     4  →  20
+ четверть     5  →  25
+ четверть  6.25  →  31.25
+ четверть  7.81  →  39.06

Вниз — делим:

16 ÷ 1.25 = 12.8

Проверка: 12.8 + 3.2 = 16. База вернулась.

Узнаёшь арифметику? Это ровно то же накопление, что ломало em в шаге 2. Разница в том, что там оно случалось само и зависело от глубины вложенности, а тут ты его считаешь один раз и назначаешь явно. Один механизм, два исхода — беспорядок и система.

В rem ступени выходят некрасивыми: 0.8 / 1 / 1.25 / 1.5625 / 1.953 / 2.441. Округляй, шкала — это отправная точка, а не закон:

0.875rem  14px   подписи, мелкое
1rem      16px   основной текст          ← база
1.25rem   20px   крупный текст, h4
1.5rem    24px   h3
2rem      32px   h2
2.5rem    40px   h1
3rem      48px   заголовок героя

Семь ступеней — этого хватает на любой сайт. Больше не нужно.

Какой коэффициент брать
1.125  очень плотно  → плотные интерфейсы: панели, таблицы, дашборды
1.2    спокойно      → универсальный выбор, если сомневаешься
1.25   выразительно  → контентные сайты, блоги
1.333  громко        → лендинги, промо
1.5+   только для 2–3 крупных ступеней, иначе разрыв между
       основным текстом и заголовком становится пропастью

Закономерность: чем больше коэффициент, тем меньше ступеней помещается до нечитаемых крайностей. При 1.333 пятая ступень вверх — это уже 50px.

Шкала отступов — отдельная и другая

Вторая шкала, её часто путают с первой. Отступы строят не на типографском коэффициенте, а на шаге в 4px, потому что они должны складываться и стыковаться:

0.25rem   4px
0.5rem    8px
0.75rem  12px
1rem     16px
1.5rem   24px
2rem     32px
3rem     48px
4rem     64px

Причина разделения: размеры шрифта воспринимаются соотношением (20 к 16 — заметный скачок, 120 к 116 — нет), а отступы работают сложением (два отступа по 8 должны дать ровно 16, а не 16.4). Разная математика — разные шкалы.

Правило одного направления

Раз берётся больший, держать отступы с обеих сторон бессмысленно — половина всё равно проглатывается. Отсюда дисциплина: вертикальные отступы задаются в одну сторону, вниз.

css
p, ul, figure { margin-block: 0 1.5rem; }   /* сверху 0, снизу 24px */

Тогда расстояние между любыми двумя блоками — это ровно нижний отступ верхнего, и читается оно из одного места.

Близость: главный принцип

Расстояние сообщает о связи. Что ближе — то воспринимается как одно целое, независимо от разметки.

Заголовок относится к тексту под ним, а не над. Значит снизу у него должно быть тесно, а сверху просторно:

css
h2 { margin-block: 3rem 1rem; }   /* сверху 48, снизу 16 */
p  { margin-block: 0 1.5rem; }    /* снизу 24 */
  …конец предыдущего раздела

           ↕ 48      ← разрыв: новая тема

  ЗАГОЛОВОК
           ↕ 16      ← тесно: заголовок и текст — одно целое
  Первый абзац раздела…
           ↕ 24
  Второй абзац…

  Соотношение важнее абсолютных чисел. Сделаешь сверху 24 и снизу 24 — заголовок повиснет ровно посередине и перестанет принадлежать чему-либо. Читатель потеряет структуру, хотя каждое число по отдельности «нормальное».

Правило в общем виде: отступ снаружи группы должен быть заметно больше, чем внутри неё. Заметно — это примерно вдвое, не на 15%.
