# Learning

Front-end coursework. A self-directed roadmap through React and
TypeScript, started July 2026. Week one covered the CSS fundamentals;
week two moves into JavaScript.

**Live pages:** https://richard-ushkalov.github.io/learning/

## Structure

One folder per day of the roadmap. Each day covers a topic and ends
with a homework page — `index.html`, `style.css`, and from day 11 an
`app.js` inside. A `sandbox/` folder holds the loose experiments that
went with the topic.
